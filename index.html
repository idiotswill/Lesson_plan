Progress, code, creations and unfinished journeys save in this browser. Keep the same launcher address and port. Export a backup before updating, changing browsers or clearing data.
Local Python
Python runs on your computer using the interpreter that launches the game. No account, CDN or AI service is used. The introductory runner permits variables, arithmetic, conditions, bounded loops and simple collections. Imports, attributes, files, network access and arbitrary function calls are disabled. Runs have step and time limits. This is a restricted teaching workbench, not a general hostile-code sandbox. Run only your own code.
Stop cancels the browser result; its disposable local process exits within four seconds. Closing this launcher stops game access. No server is exposed to other computers.
Scope
This build connects five introductory systems. It is not a complete course or a mastery assessment. Digital-systems and computing activities are foundational models; broader material remains to be developed and verified.
